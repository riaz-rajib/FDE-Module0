# Evidence model

Every material claim records one execution mode and one validation method.

Execution modes: Portable, Rendered, Synthetic, Local live, Provider live, Unproved.

Validation methods: Machine-verified, Assessor-observed, Peer-observed, Customer-simulated, Document-reviewed.

Observation does not upgrade the execution mode. A synthetic exercise observed by an assessor remains `Synthetic + Assessor-observed`.
